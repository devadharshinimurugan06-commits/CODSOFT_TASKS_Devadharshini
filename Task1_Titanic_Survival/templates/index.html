ABOUT THE EXPERIENCE

A Story Explored Through Data

Beyond the Veils is an interactive Titanic survival prediction project. It uses passenger information and a trained machine learning model to estimate survival probability.

⌕

How It Works

Enter passenger details, submit the form, and receive a model-generated survival estimate.

✧

Technology

CatBoost, Flask, Python and SHAP explainability power this application.

◉

What-if Analysis

Compare two hypothetical passenger profiles using the same trained model.

BEYOND THE VEILS.

Inspired by the story of the RMS Titanic

Built with CatBoost · Flask · Explainable AI

Educational demonstration using historical Titanic data. Predictions are estimates, not facts about individual passengers.
